# API Contract

---

## 1. Загрузка договора

### `POST /upload`

**Что делает:** Загрузка файла (pdf/docx) + сразу обработка документа.

**Успешный ответ (201 Created):**
```json
{
    "id": "162345",
    "filename": "contract.docx",
    "upload_date": "2026-07-29",
}
```
**Ошибка (400 Bad Request):**

```json
{
    "error": "Неправильный формат файла"
}
```
